# XVML

[![NuGet](https://img.shields.io/nuget/v/XVML)](https://www.nuget.org/packages/XVML/)

XVML — это гибкая и лёгкая библиотека-парсер для файлов `.xvml` в проектах Unity и .NET.

### Возможности

- Полная поддержка объектов, массивов и примитивов JSON  
- Корректная обработка типов при конвертации  
- Возможность загрузки JSON-файлов и сохранения их в XVML  
- Полностью совместимо с Unity и .NET  
- Идеально подходит для перехода со старых JSON-сохранений
